# Glosario de operaciones de almacenes

> **Documento ficticio para el workshop de Amazon Quick.** Los términos y criterios son de ejemplo y no reflejan definiciones internas reales de Grupo Éxito.

| Término | Definición |
| --- | --- |
| **SKU** | Código único de un producto en una presentación específica (por ejemplo, ABA-001 = Arroz blanco 1 kg). |
| **Almacén** | Punto de venta físico. Se identifica con un código: marca (EX = Éxito, CA = Carulla, SM = Surtimax, SI = Super Inter), ciudad y número, por ejemplo SM-BOG-01. |
| **Formato** | Tamaño del almacén: Grande, Mediano o Barrio. Determina el surtido y el stock mínimo. |
| **Stock mínimo** | Unidades que cubren cerca de 5 días de venta de un SKU en un almacén. Por debajo de este nivel se debe reponer. |
| **Quiebre de stock** | Un SKU cierra el día con stock en cero en un almacén. Se mide en días-SKU. |
| **Días-SKU en quiebre** | Suma de los días en que cada SKU estuvo en quiebre. Tres SKU en quiebre durante dos días suman 6 días-SKU. |
| **Venta perdida** | Venta que no ocurrió porque el producto no estaba disponible. Cada venta perdida es un cliente que quizá no regresa. |
| **Rotación** | Velocidad con que se vende el inventario de un SKU; alta rotación significa que se vende rápido. |
| **Reposición** | Envío de producto desde el centro de distribución al almacén para volver al nivel de stock deseado. |
| **Transferencia entre almacenes** | Traslado de producto de un almacén donante a otro almacén de la misma ciudad para evitar un quiebre (ver POL-OPS-003). |
| **Almacén donante** | Almacén con stock mayor a 2 veces su mínimo que puede ceder unidades. |
| **Cadena de frío** | Conjunto de controles que mantienen un producto refrigerado entre 2 °C y 6 °C (ver POL-OPS-002). |
| **Cuarentena** | Ubicación del sistema donde se bloquean productos que no se pueden vender hasta que Calidad los revise. |
| **Gerente regional** | Responsable de un grupo de almacenes de una zona operativa; aprueba transferencias. |
| **Temporada de lluvias** | Período en que sube la demanda de café, chocolate y avena, más marcada en las ciudades andinas. |
